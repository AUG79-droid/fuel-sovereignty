# Fuel Sovereignty | Strategic Fuel Resilience Simulator

Interactive bilingual (English / Spanish) aerospace In-Service fuel-supply resilience simulator.

## Application

The entire application is in [index.html](./index.html). It includes six escalating crisis rounds, associated technical theory, illustrative operational scenarios, decision analysis, a visual supply model, self-contained images, and simulated financial values in euros.

All figures and scenarios are fictional training examples, not Airbus operational data, verified fuel prices, approved military procedures or airworthiness guidance. The hyperrealistic chapter images are AI-generated illustrations, not documentary Airbus photographs.

## Launch

Open [index.html](./index.html) locally in a browser or visit the GitHub Pages site after Pages is enabled:

https://aug79-droid.github.io/fuel-sovereignty/
